## User Stories
1. As a bank operations auditor, I would like to filter transactions by date ranges, specific ATMs, customer PAN, and transaction metadata so that I may efficiently locate relevant transactions for inspection.
2. As a bank operations auditor, I want to export and print filtered transaction data tables so that I can improve my audit reports and record-keeping.
## Running the Code
This project was completed using Next.js under Node.js. It should be that `npm` (Node.js) is all that is needed.
1. Run `npm install` under the project root directory to download the dependencies and libraries necessary to run the code.
2. Then, in the same directory, run `npm run dev` to initiate the frontend server.
3. You should now be able to access the Transactions page at http://localhost:3000/transactions.
